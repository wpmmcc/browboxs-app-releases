# browboxs-app-releases

Public **compiled artifacts only** for the browboxs workbench:

- `browboxs-desktop-*` / installers (deb, AppImage, msi, dmg)
- `browboxs-agent-*`
- `browboxs-server-*`

**Not in this repo:** fingerprint browser engines (see [browboxs-engines-releases](https://github.com/wpmmcc/browboxs-engines-releases)).

Official website / node domains: private (not published here).

Docs: product install + dual-channel updates (`INSTALLERS-AND-UPDATES.md` in source tree).
